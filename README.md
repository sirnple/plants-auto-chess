# 植物自走棋 (Plants Auto Chess)

融合金铲铲之战与植物大战僵尸的策略游戏

![Game Preview](docs/preview.png)

## 🎮 游戏介绍

**植物自走棋**是一款结合了自走棋策略深度和塔防乐趣的游戏。玩家需要在每回合的商店中购买植物，通过合成升星，部署到战场上，抵御20波僵尸的进攻。

📚 **[完整设计规格文档](./docs/spec/00-INDEX.md)** - 包含详细的游戏设计、系统架构、开发规范

### 核心特色

- 🎯 **自走棋机制**: 商店购买、合成升星、羁绊搭配
- 🧟 **塔防战斗**: 植物自动攻击，抵御僵尸进攻
- 🔗 **羁绊系统**: 7种羁绊，策略搭配
- ⚔️ **20回合挑战**: 难度递增，Boss战
- 🎒 **装备系统**: 击败僵尸掉落装备，强化植物
- ✨ **华丽特效**: 攻击、死亡、升星特效

## 🚀 快速开始

### 环境要求
- Node.js 18+
- npm 或 yarn

### 安装运行

```bash
# 进入项目目录
cd plants-auto-chess

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

### 游戏操作

1. **购买植物**: 点击商店中的植物消耗阳光购买
2. **合成升星**: 3个相同的1星植物自动合成2星，3个2星合成3星
3. **部署植物**: 点击备战区植物选中，再点击战场格子部署
4. **收回植物**: 点击战场上的植物可收回备战区
5. **刷新商店**: 消耗2阳光刷新商店植物
6. **开始战斗**: 部署完成后点击"开始战斗"
7. **使用装备**: 击败僵尸掉落装备，点击使用

## 🏗️ 技术栈

- **游戏引擎**: Phaser 3 (v3.70+)

## ⚙️ 开发规范

### Spec-Driven Development

本项目采用规格驱动开发:
1. `docs/DESIGN_SPEC.md` - 设计规格文档
2. `docs/BALANCE.md` - 平衡性调整记录
3. 按Task拆解实现

### 代码风格

- 使用 TypeScript 严格模式
- 路径别名: `@/*` 指向 `src/*`
- 系统分离: 每个系统独立文件
- 实体组件: Plant/Zombie/Projectile/Item
