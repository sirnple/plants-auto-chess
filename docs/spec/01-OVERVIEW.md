# 01-OVERVIEW.md - 产品概述

## 一句话描述

"用自走棋的策略深度，玩植物大战僵尸的塔防乐趣"

## 核心体验

### 策略层
- 每回合在商店中决策购买、合成、部署
- 考虑羁绊搭配，构建最强阵容
- 经济管理：何时刷新、何时存钱

### 战斗层
- 自动战斗，欣赏自己构建的防线
- 植物自动发射子弹攻击僵尸
- 僵尸沿行向基地移动

### 成长感
- 三星植物、四星植物的强力反馈
- 羁绊激活时的视觉特效
- 装备收集和强化

## 目标平台

- Web端（桌面浏览器优先）
- 支持 Chrome/Firefox/Safari/Edge
- 分辨率: 1200x800 (16:10)

## 目标用户

- 植物大战僵尸爱好者
- 自走棋玩家
- 塔防游戏爱好者
- 喜欢策略深度的休闲玩家

## 核心循环

```
[准备阶段] → [购买/部署] → [战斗阶段] → [结算奖励] → 循环
   ↑                                              ↓
[游戏结束] ←────────── 基地血量 ≤ 0 ──────────────┘
```

## 游戏时长

- 单局时长: 15-25分钟
- 回合数: 20回合
- 每回合操作时间: 无限制（点击开始战斗进入下一阶段）

## 胜利条件

存活20回合，击败最终Boss（僵王博士）

## 失败条件

基地生命值降为0

## 核心差异化

| 游戏 | 我们的融合 |
|------|-----------|
| 金铲铲之战 | 自走棋机制（商店、合成、羁绊） |
| 植物大战僵尸 | 塔防战斗（行-based、自动攻击） |
| 植物自走棋 | **两者的完美融合** |

## 关键设计原则

1. **简单易上手**: 植物大战僵尸玩家无需学习即可理解基本操作
2. **策略有深度**: 自走棋玩家可以享受羁绊搭配和阵容构建
3. **自动战斗**: 战斗阶段无需操作，专注策略规划
4. **渐进解锁**: 新植物随回合解锁，保持新鲜感
