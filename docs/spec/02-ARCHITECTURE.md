## 系统说明

### 核心系统

#### 1. 战斗系统 (BattleSystem)
**职责**: 管理战场、实体更新、战斗逻辑

**核心功能**:
- 战场网格管理 (5行 x 8列)
- 植物部署与收回
- 僵尸生成与移动
- 子弹飞行与碰撞检测
- 战斗胜负判定

**关联系统**:
- 接收 WaveSystem 的僵尸生成请求
- 触发 EffectSystem 的特效播放
- 通知 GameScene 基地受损

#### 2. 商店系统 (ShopSystem)
**职责**: 商店刷新、植物购买

**核心功能**:
- 商店槽位管理 (5个)
- 植物刷新与锁定
- 购买验证（阳光检查）
- 植物解锁（随回合解锁新植物）

**关联系统**:
- 与 MergeSystem 协作，购买后添加至备战席

#### 3. 合成系统 (MergeSystem)
**职责**: 自动检测并执行植物升星

**核心功能**:
- 备战席管理 (8格)
- 合成检查 (3合1)
- 星级成长 (1星→2星→3星→4星)
- 自动合成触发

**关键设计**:
- 循环合成：一次检查中可能触发多次合成
- 满员购买：满员但能合成时允许购买
- 详见 [11-SHOP.md](./11-SHOP.md)

#### 4. 羁绊系统 (SynergySystem)
**职责**: 计算已部署植物的羁绊加成

**核心功能**:
- 羁绊计数
- 阈值判断 (2/3/4/5个激活不同等级)
- 效果应用 (攻速、血量、伤害等)

**羁绊类型**:
- 阳光系、射手系、防御系、爆破系、冰霜系、火焰系、辅助系
- 详见 [12-SYNERGY.md](./12-SYNERGY.md)

#### 5. 波次系统 (WaveSystem)
**职责**: 生成僵尸波次，控制游戏难度

**核心功能**:
- 20回合波次配置
- 僵尸生成时机控制
- 难度递增曲线
- Boss战处理

**详见**: [21-WAVES.md](./21-WAVES.md)

#### 6. 装备系统 (ItemSystem)
**职责**: 装备掉落、管理、使用

**核心功能**:
- 装备掉落（击败僵尸概率掉落）
- 装备栏管理
- 装备效果应用
- 消耗品使用

**装备类型**:
- 武器（加攻击）、防具（加血量）、饰品（特殊效果）、消耗品（一次性）

#### 7. 特效系统 (EffectSystem)
**职责**: 管理所有视觉特效

**核心功能**:
- 攻击特效
- 死亡特效
- 合成升星特效
- 伤害数字飘字
- 屏幕震动

#### 8. 音效系统 (AudioSystem)
**职责**: 管理游戏音效和背景音乐

**核心功能**:
- 背景音乐播放
- 音效触发（攻击、合成、购买等）
- 音量控制

### 实体定义

#### 植物 (Plant)
**属性**:
- 配置数据（名称、emoji、费用等）
- 星级 (1-4星)
- 当前生命值 / 最大生命值
- 攻击力
- 攻击冷却
- 所在位置（行、列）

**行为**:
- 更新（每帧）
- 攻击（发射子弹）
- 受伤（扣血）
- 死亡（销毁）
- 治疗（回血）

#### 僵尸 (Zombie)
**属性**:
- 配置数据（名称、emoji、速度等）
- 当前生命值 / 最大生命值
- 攻击力
- 所在行
- 位置（像素坐标）
- 减速状态

**行为**:
- 更新（每帧）
- 移动（向左）
- 攻击（攻击植物）
- 受伤（扣血）
- 死亡（销毁）

#### 子弹 (Projectile)
**属性**:
- 类型（豌豆、寒冰、尖刺等）
- 伤害值
- 特殊效果（减速、范围等）
- 飞行方向

**行为**:
- 更新（每帧飞行）
- 碰撞检测
- 命中处理

#### 装备 (Item)
**属性**:
- 配置数据（名称、emoji、类型等）
- 稀有度（普通/稀有/史诗/传说）
- 效果

**行为**:
- 装备（应用到植物）
- 卸下
- 使用（消耗品）

## 数据流向

```
用户输入 → 游戏场景 → 相应系统 → 更新实体 → 渲染更新
                              ↓
                         触发事件 → 更新UI
```

## 模块间通信

### 事件驱动
使用事件机制解耦模块：

| 事件名 | 触发时机 | 监听者 |
|--------|---------|--------|
| zombieKilled | 僵尸死亡 | GameScene（加阳光） |
| sunGenerated | 产生阳光 | GameScene（更新UI） |
| zombieReachedBase | 僵尸到达基地 | GameScene（扣生命） |

### 直接调用
系统间需要同步数据时使用直接调用：
- GameScene 调用各 System 的更新方法
- System 返回数据给 GameScene 更新UI

## 扩展性设计

### 添加新植物
1. 在植物配置中添加数据
2. 设置解锁回合
3. 如有新机制，修改相应 System

### 添加新羁绊
1. 在羁绊配置中添加数据
2. 修改羁绊计算逻辑
3. 添加新的效果类型

### 添加新系统
1. 创建新 System 类
2. 在 GameScene 中初始化和更新
3. 与现有系统通过事件或接口通信
