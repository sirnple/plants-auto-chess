## 交互设计

### 操作方式

| 操作 | 说明 |
|------|------|
| 左键点击商店 | 购买植物 |
| 左键点击备战区 | 选中/取消选中植物 |
| 左键点击战场空格 | 部署选中的植物 |
| 左键点击战场植物 | 收回植物到备战区 |
| 信息模式下点击植物 | 显示详细信息 |
| 点击卖出按钮 | 卖出植物 |

### 信息模式设计

**问题**: 最初使用右键显示信息，但用户反馈不好。

**解决方案**: 使用"信息模式"切换按钮

**流程**:
1. 点击顶部"ℹ️ 信息模式"按钮进入信息模式
2. 按钮高亮显示
3. 点击植物显示详细信息面板
4. 面板包含：属性、卖出按钮
5. 4秒后自动消失

**优点**:
- 符合自走棋游戏习惯
- 不会误触发
- 清晰的用户反馈

## 响应式考虑

**注意**: 当前设计固定1200x800，不做响应式适配。

如果需要适配其他分辨率，考虑：
1. 使用 `Phaser.Scale.FIT` 保持比例
2. 缩放UI元素
3. 或者开发移动端专用布局

## 常见问题

### Q: 为什么不用右键？
A: 右键在浏览器中可能触发上下文菜单，用户体验不好。信息模式更明确。

### Q: 为什么信息面板4秒后消失？
A: 避免遮挡战场，同时给用户足够时间阅读和操作（卖出）。

### Q: 为什么备战席在底部？
A: 符合自走棋游戏习惯（如云顶之弈、金铲铲），且不会遮挡战场。
